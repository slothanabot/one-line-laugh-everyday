Entry for make.fun's **One-Line Laugh Sprint** (`u-daring-gecko-25-one-line-laugh-sprint-cda708b2`): one original funny line, at most 200 characters, on everyday life. This entry takes the morning alarm / coffee angle — a coffee machine with a mind of its own, pushed too far by one too many snoozed alarms.

## The line

> My coffee machine requested a transfer this morning — brewing for someone who snoozes through three alarms is officially a hostile workplace.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic, no network, no model calls, no file reads outside the repo.
